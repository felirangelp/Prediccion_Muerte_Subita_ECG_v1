📊 Información del Proyecto

Este proyecto implementa tres modelos avanzados de Machine Learning para la predicción de muerte súbita cardíaca mediante análisis de señales ECG:

  • Modelo Sparse: 94.2% accuracy, 97.9% AUC-ROC
  • Modelo Hierarchical: 87.9% accuracy, 86.7% AUC-ROC
  • Modelo Hybrid: 74.8% accuracy, 85.9% AUC-ROC
💡 Nota Importante: Si los dashboards no cargan en GitHub Pages, haz clic en "Descargar Dashboard" y abre el archivo descargado en tu navegador. Los dashboards son archivos HTML autocontenidos que funcionan perfectamente al abrirlos localmente.
